# 어노테이션(@) 이해하기
참고출처 : https://hianna.tistory.com/1171

## 1. 어노테이션 = "스프링에게 보내는 편지"
우리가 클래스 위에 @를 남기면 **Spring이 이해 가능**하게 메모를 써 붙혀 놓는 것과 같다.
이게 **붙어있지 않으면** Spring이 이해하지 못해서, 관리하지 못하고 **작동하지 않는다.**(완전 무시)


## 2. 역할 부여 스티커(계층 구조)
이 명찰을 달아야 스프링이 '빈(Bean)'으로 등록해서 관리해 줍니다. (Bean : 스프링이 관리하는 객체)

### @Controller
- @Controller는 화면(HTML)을 돌려줄 때 쓰고, @RestController는 데이터(JSON)를 돌려줄 때 씁니다. 요즘은 주로 @RestController를 많이 씁니다.

### @Service
- 이게 있어야 비지니스 로직 구현이 가능하다

### @Repository
- DB 관련 예외가 터지면 스프링이 알아서 처리해주기도 한다. (JPA를 쓰면 생략 가능하기도 함.)


## 3. 연결 스티커(의존성 주입)
클래스들을 연결해주는 @

### @RequireArgsConstructor
- 내 클래스에 final이 붙은 변수가 있으면, 자동으로 채워주는 생성자를 만듦
- 코드가 훨씬 깔끔해지고 안전함.


## 4. 대장 스티커

### @SpringBootApplication
- 이 스티커가 붙은 위치부터 하위 패키지를 싹 뒤져서, 위에 말한 @Controller, @Service 붙은 애들을 다 찾아냅니다. (그래서 파일을 엉뚱한 곳에 만들면 안 되는 겁니다.)
